SIMATS COURSE REGISTRATION PORTAL

Files:
- index.html
- style.css
- script.js

How to run:
1. Extract the ZIP.
2. Open index.html in Chrome/Edge.
3. Fill the registration form and select courses.
4. Open F12 -> Console to see JavaScript debugging output.

Requirements covered:
1. Semantic HTML structure, navigation and contact details.
2. Six-course HTML table.
3. Ordered/unordered lists and internal/external links.
4. Complete registration form.
5. CSS selectors, box model, Grid/Flexbox, responsive media queries and hover effects.
6. Browser-side validation for mandatory fields, email and semester.
7. JavaScript course array and dynamic course selection.
8. Reusable calculateSummary() function.
9. Dynamic registration summary without page reload.
10. console.log() debugging in Developer Tools.

Note:
The current official name is Saveetha Institute of Medical and Technical Sciences (SIMATS), formerly Saveetha University. This demo uses SIMATS branding and sample course data for the assignment.
